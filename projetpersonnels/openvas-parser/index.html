< Analyse automatisée de scans OpenVAS >

Projet personnel : transformation d’un rapport OpenVAS en données exploitables (tri / priorisation).

Contexte

Objectif : faciliter la lecture d’un scan en automatisant l’extraction des vulnérabilités et la priorisation.

Le script produit une sortie structurée (CSV) pour analyse.

Objectifs

  • Extraire les vulnérabilités clés d’un rapport
  • Prioriser (sévérité / hôtes / occurrences)
  • Exporter en CSV pour traitement

Démarche

  1. Analyse du format d’entrée
  2. Implémentation parsing + normalisation
  3. Export CSV et contrôles

Compétences mobilisées

  • Vulnérabilités
  • Traitement de données
  • Python
